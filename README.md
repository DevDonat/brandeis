# BRANDEIS

Statički sajt obrta za čišćenje u Daruvaru.

- `index.html`: početna stranica
- `usluge.html`: usluge, karusel i detalji usluga
- `style.css`: izgled i mobilni prikaz
- `app.js`: prozorčići i karusel
- `assets/`: slike koje sajt koristi

Otvorite index.html za lokalni pregled. Kontakt dugmad vode na WhatsApp.

Za GitHub Pages: izvor main grana, mapa / (root).
